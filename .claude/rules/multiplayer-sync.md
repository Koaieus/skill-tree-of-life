Sync is host-authoritative intent-up / confirmed-command-down: the host decides, every peer applies through one serial applier, and VFX is a pure observer that never mutates — so never *frame-order* a mutation, never put a node/entity *reference* in a command (`stable_id` / `entity_id` only), and never roll unseeded (bare `Array.shuffle()`) for a result a peer must *reproduce* rather than receive; host-only rolls (loot) are exempt.
