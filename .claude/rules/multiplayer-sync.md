Sync is host-authoritative intent-up / confirmed-command-down (**re-decided 2026-08-24 — lockstep's old grounds are all retired, read the doc before re-arguing it**): never put a node/entity *reference* in a command (`stable_id`/`entity_id` only), never roll unseeded for a result a peer *reproduces* rather than receives (host-only rolls exempt), and never use a transcendental (`log`/`exp`/`pow`/`sin`/`cos`) in gameplay code or a stat formula — peers recompute derived stats rather than receive them.
