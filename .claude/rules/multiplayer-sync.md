Sync is host-authoritative intent-up / confirmed-command-down (**re-decided 2026-08-24 — lockstep's old grounds are all retired, read the doc before re-arguing it**): never put a node/entity *reference* in a command (`stable_id`/`entity_id` only), never roll unseeded for a result a peer *reproduces* rather than receives (host-only rolls exempt), and never use a transcendental (`log`/`exp`/`pow`/`sin`/`cos`) in a value a peer *recomputes* — the stat pipeline, auras, any derived stat — while a value a peer *receives* (anything that ships in a command or an `AttackRecord`: attack/spell resolution, procgen) is unconstrained; `mise run lint-transcendentals` is path-based and coarser, and an allowlist entry with its end-condition is how you claim the received side (#706).
