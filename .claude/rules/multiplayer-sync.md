Sync is host-authoritative intent-up / confirmed-command-down: the host decides, every peer applies through one serial applier, and VFX is a pure observer that never mutates — so never *frame-order* a mutation (a fixed logical clock, e.g. `BeatClock`, is fine; animation completion or wall-clock timing is not), never put a node/entity *reference* in a command (`stable_id` only), and never call bare `Array.shuffle()` on anything gameplay-affecting.
