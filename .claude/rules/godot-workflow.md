Godot fails silently across a dozen authoring situations — an editor pass round-trips scenes and can strip `.tres` fields, a stale `class_name` cache breaks parsing, a hand-authored `.tres` UID mismatch nulls the field, `@tool` scripts serialize derived values back into the scene, `.gdshader` errors survive a headless import, and a deferred call holding a freed Object is dropped. Check before you author or refresh, and always `git diff` after an editor pass. See docs/domain/godot-workflow.md
