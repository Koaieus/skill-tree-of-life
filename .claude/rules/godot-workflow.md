Run `mise run refresh` for a headless editor refresh — it prints a verdict, so never hand-diff editor churn; refresh freely and move on. Four symptoms route to the doc: *"Could not find type X"* on a new `class_name` (stale cache — refresh); a tracked `.uid` pointing at nothing after moving a `.gd` (sweep orphans); *"Identifier not found: StatRegistry/Events"* from a throwaway `godot --script` (it skips autoloads — use a GUT test); and any check the headless suite can't judge — glow, z-order, shader output — which needs a real frame.
