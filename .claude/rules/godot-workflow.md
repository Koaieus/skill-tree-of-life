`mise run refresh` is a headless editor pass with a verdict — never hand-diff editor churn. Symptoms that route to the doc: *"Could not find type X"*, or a low test count after a rebase / in a new worktree (stale cache — refresh, don't debug); an orphan `.uid` after moving a `.gd`; a runtime *"Nonexistent function"* on a file you just wrote (a parse error `check` missed — `--check-only --script <file>`, never refresh); *"Identifier not found: StatRegistry"* under `godot --script` (skips autoloads — use GUT); glow / z-order / shaders / text that is mushy or breaks up at a camera zoom need a real frame; an *invalid UID* warning after editing an `.import`; a `:=`-inferred var fed by `Dictionary.keys()`/`.values()` failing to compile only under GUT, never under `mise run check` (typed-Dictionary key/value types erase to Variant through `.keys()`/`.values()` — annotate the loop var explicitly, e.g. `for spell: SpellDef in dict.keys():`).
