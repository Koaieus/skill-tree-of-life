`mise run refresh` runs a headless editor pass — it prints a verdict, so never hand-diff editor churn; refresh freely and move on. Symptoms that route to the doc: *"Could not find type X"* on a new `class_name`, or a low test count after a rebase / in a fresh worktree (stale cache — refresh, don't debug); an orphan `.uid` after moving a `.gd`; *"Identifier not found: StatRegistry/Events"* from a throwaway `godot --script` (it skips autoloads — use a GUT test); and glow, z-order or shader output, which no headless suite can judge — needs a real frame.
