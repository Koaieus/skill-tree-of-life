# Baked WHITE, not the #8CD9FF the other folders use, via the `#fg` directive
# below. A baked colour is a colour no caller can take back: `ArmedMode`'s
# `icon_tint()` multiplies STR-red over a cyan-baked sword and gets mud. White
# is the neutral base a modulate can actually steer, and it is also exactly what
# this menu already shipped.
#fg #ffffff
#
# Save/Load are ONE piece of art with its arrow reversed - the same floppy read
# as write-to-disk and read-from-disk. Restart is circular and Main Menu is a
# house on purpose: the set they replace used the same back-arrow glyph for
# both, so the two most consequential buttons in the menu looked alike.

menu_save	delapouite/save.svg
menu_load	delapouite/load.svg
