## Merge protocol

`/warp` ends in a **fast-forward**, so only one merge can be in flight at a time
— the orchestrator's OK is a merge token, not a verdict handed to two drones at
once. A drone whose branch has fallen behind must `git rebase master`, re-run
`mise run check` and its targeted tests, then fast-forward.
