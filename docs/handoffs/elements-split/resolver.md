Child 4 of the #1716 elements split (design home `docs/design/elements.md` § Landing resolution; ADR 0082, with ADR 0083 for the order inside stage one): the two-stage hit resolver, gather only. Stage one gathers a hit's whole target set from terrain at land time, at each node admit / land / read; stage two lands the payload once per gathered entry, and a go-off also lands one entry on its own node (the whole hit). Today's explosive detonation is **not touched here**: it keeps running on its own compile-time path (`DetonateEffect`, both ledgers, the per-wave scope) until #{go-off-zero} ports it, so the game keeps its blast throughout.

Blocked by: #{defs}, #{terrain}, #{flow}, #{applier}
Blocks: #{go-off-zero}

## Acceptance spec

**Decisions** (owner, 2026-11-09 unless dated)
- Two stages: *"resolve elements first which settles the reach [as in, total set of targets] for the hit (including cascades..?) and then resolve the remainder of the hit for each target (riders, damage?)"* (`docs/design/elements.md:651-677`; ADR 0082 §1-2, its §1 pre-hit read replaced by ADR 0083 §1).
- Riders first (owner, 2026-11-10): *"first resolve terrain riders (only: heat/cold/charge) - then resolve hit reach + local reach"*. At each node of stage one the element riders land, then the node's primed states and their power are both read from the result, so the hit that tips a node over T sets it off itself (ADR 0083 §1). The steps at a node are admit / land / read (ADR 0083 Consequences).
- Frozen reads at two points (owner, 2026-11-10, picked *admit on arrival, the rest after riders*; ADR 0083 §2): an arriving copy is admitted or absorbed against the node as it arrives, and an absorbed copy lands no riders; the path-end and the break check read after the hit's element riders land. This unit owns both seams (the admit step, and a second `Admits` read after the riders) and the place where a spell walk ends on that answer. #{ice} implements the answers (land / absorb / land + break) and owns no gather code.
- Unit is one hit: *"landing arrow = 1 hit (+optional reach etc) / landing blade contact = 1 hit / 1 spell WAVE = 1..N hits"*. A wave is N gathers (`:697-701`). Built at land time, not compile time (`:684-693`).
- One owner for the gather with an element callback: *"option 1 looks squeaky clean"*. An element answers *admits* and *go off* and nothing else (`:691-696`).
- Crit per arrival, at the gather head: *"option 1. does it then also do the CritCondition?"* — yes (`:706-713`). The conditions and the roll still read the node as it was before this hit, ahead of the hit's own riders (ADR 0083 §4): two read points inside one hit, on purpose.
- Per-hit once-per-node set, one terrain snapshot per beat: *"option 1. and can we make it order independent somehow?"*, then *one snapshot per beat*. Same-beat hits land their element riders as sums on the pre-beat terrain, the go-offs are read from that summed terrain, and the spends are summed and clamped at 0 (`:714-729`; ADR 0083 §5).
- One share scales the whole payload, `ceil` per rider, one knob per go-off (`:730-733`; taken as settled by the pass). Its default is 1 since the whole-hit call below, so the round-up is idle at the default.
- Spend law, 2026-11-08: a go-off pays *1 per node it reaches*; a disc reaching no other node does not go off; a spend digs under T (`:79-97`; ADR 0081 §1). Primed-ness and power are both read post-land (ADR 0083 §1). The gather commits the spend a go-off returns and never derives it from the count of nodes reached: a go-off a cast's shape has enlarged reaches more nodes than the node pays for (the node pays its solo cost, ADR 0084 §4; that go-off is #{cast-shapes}'s). The centre landing (below) is not a node reached: the law stands as worded, so the default spend does not count it.
- Chains are flat, `damage × s` and riders `ceil(r × s)`, never `s^k` (2026-11-05, `:489-496`). A copy lands raw (#1733 R2, `:525-530`). A copy carries its parent's crit (ADR 0082 §4).
- Riders are one summed entry per status id per landing entry (`:334`). In-hit order is *"elemental riders first … then other status(es), then damage(s)"* (`:342-344`); per target the aspect riders still land before the damage (ADR 0083 §3; ADR 0067 unchanged). A hit carries 0 or 1 element (`:155-157`).
- Greed: *"i think Greed shouldn't multiply incoming Heat/Cold/Charge stacks"* (`:159-163`). Only this guard ships here.
- **Every landing is a whole hit, and a go-off lands on its own node too** (owner, 2026-11-10, night, picked over share ½ with the centre excluded and over share 1 with the centre excluded: *"the hit hits *and* the blast hits, and the arc hits, and share 1 means no rounding for rider stacks"*; `docs/design/elements.md` § Landing resolution, that paragraph; no ADR carries it yet). It changes ADR 0082's share default and ADR 0084 §5's "the seed node takes the seed once". Each channel that goes off lands one more payload on the node it goes off from: the hit node takes 1 + 1 per channel that goes off from it, a node one channel reaches takes 1, a node both reach takes 2. Terrain riders still land once per node per hit (stage one's cap), so the extra landings carry damage and aspect riders only. "No other node reached, no go-off" stands: the centre landing happens only when the go-off does. A cast's shape alone is not a channel for the seed (owner, 2026-11-10: *"the shape for spells hmmm i think that one shouldn't count"*). The pass reading that a shape added into a primed node's go-off of the same element is one channel (the seed takes 2) is tentative and #{cast-shapes}'s. Frozen's shatter tuned to match the doubling stays open (#{ice}).
- Dual reach (owner, 2026-11-10): *"riders twice, payload twice. charged burning nodes sounds like a dangerous concept"*. A node gathered by two reaches is two entries, each landing the damage and the aspect riders at its share; its terrain riders land once (the whole-hit cap above). On the same call: the node's own go-off fires once per hit (owner, 2026-11-10, picked over once per gathered entry), through the once-per-node set, and the dedupe stays a one-line switch (`:770-781`). A cast's shape and a go-off of another element are two reaches under the same rule (owner, 2026-11-10, picked *same as dual reach: concatenate*; ADR 0084 §5): a node inside both takes one copy per reach, and the one dedupe switch covers both cases. The seed node takes the hit once plus one centre copy per channel that goes off from it, and a shape's reach adds none. The shape's reach itself is #{cast-shapes}'s. A go-off picks its nodes by shape alone, allocated or not, at every level (owner, 2026-11-10: *"so far just keep it shape blind always"*; `:532-542`; ADR 0084 §7); the hit's mask decides who the copies hurt.

**Knobs** (tentative, easy to change)
- `GoOff.share` = 1.0, `@export_range(0.0, 1.0, 0.05)` on the `GoOff` base. It is the share for that go-off's copies, its centre copy included: damage × s and riders ceil(r × s).
- `GoOff.lands_on_own_node: bool = true` on the `GoOff` base: whether the go-off adds the centre copy. The base and every element's go-off keep `true` (the whole-hit call). #{go-off-zero}'s disc sets it `false`, so today's explosive keeps no centre landing until the Catalyst retag (tentative, not the owner's: go-off zero's exemption is an open owner question).
- `dedupe_dual_reach: bool = false` (`false` = concatenate, the owner's tentative option 2), an `@export` on the gather's tunables resource: a new `Resource` script beside the gather class, with one default `.tres` the gather preloads (as `BladeNode.DEFAULT_STYLE` preloads its style). A test hands the gather its own instance. File names follow the gather's (the drone's). Why an export and not a code switch: the doc keeps the dedupe *"as a knob rather than a structure"* (§ Landing resolution, "Dual reach"), a knob is an `@export` on its owner and never a `const` (`docs/domain/tunables.md`), and flipping it is ADR 0084's own revisit-when. It is the only dedupe switch: it runs over the hit's reach lists whatever produced them, so it also decides a cast's shape against another element's go-off (ADR 0084 §5). #{pairs} reads it and adds none. Editor feedback: none in this unit (no live go-off on master); it is an inspector bool.

**Composition**
- **The gather** (one class under `attack/outcome/`; name is the drone's) owns a hit's once-per-node set and its entry list (node, share, parent, generation, reach, own damage). Stage one runs inside #{applier}'s worklist drain, per beat. A beat is one `schedule_index` group (the group `apply` already flushes removals on); a spell wave is one beat. The beat's heads start from one pre-beat snapshot of the node's terrain ints (#{terrain}), and each node runs three steps in this order (ADR 0083 §1, §5). *Admit*: `Admits`' first read is asked about every arrival against the terrain the generation starts from, before any of that generation's riders land; a refused copy is dropped whole, landing no rider and making no entry. *Land*: the admitted arrivals' element riders land as sums on that terrain, through #{flow}'s shared settle routine (which nets Heat × Cold). *Read*: `Admits`' second read is asked first (below), then the node's primed bands and their power are read from the summed result, never from the pre-beat snapshot, so a rider that carries a node past T sets it off in the same hit; each go-off is computed from that read, and the spends (every go-off's, and a break's) are committed together through the same settle routine (summed, clamped at 0). Land and read run once per node per hit (the once-per-node set): a node already landed this hit takes a later admitted arrival as a payload entry only, and its go-off does not fire again. The reached nodes form the next generation and run the same three steps on the copies' element riders (`ceil(r × s)`), starting from the terrain the previous generation left. Each primed band present at read fires its own `GoOff` and appends its own list (a reach). The lists are concatenated unless `dedupe_dual_reach` is on, in which case a node keeps one entry across all the hit's reach lists. The gather is the only terrain writer, and it records its terrain changes on the hit for peers to replay (ADR 0077).
- **The centre copy** (whole hit). When a band's go-off goes off and its `lands_on_own_node` is true, the gather appends one more entry to that go-off's reach: the node it went off from, at that go-off's share, `paired` to the head like every copy (so it carries the head's crit). Stage two never lands a terrain rider: terrain riders land in stage one only, once per node per hit, so the centre copy, a node's second entry from another reach and an entry from a later generation all land damage and aspect riders only. A go-off reaching no other node does not go off and adds no centre copy. Only a band's go-off adds one: a reach with no band behind it adds none.
- **The head** is the first hit of a landing's placed span (`HitLanding.place()`, `hit_landing.gd:137-156`). For a status-only spell landing, that is its first rider. `place()` marks it. The head also carries the hit's load, an int that is 0 unless the landing site sets one. Which load each site sets (a spell's `DetonateUse` load, a blade piece's charges, 0 for an arrow) is #{go-off-zero}'s. A copy's load is 0, as a chained blast is a zero-load hit today (`detonate_effect.gd`, `load`). The element riders land in stage one at the head and are skipped in stage two. Stage two is the existing compile-and-land path per entry: each copy is compiled through the landing's stamping callable (#{applier}) and pushed onto the worklist.
- **Crit.** The head decides the arrival's crit once. `_stamp_crit_conditions` moves from compile (`spell_resolver.gd:551-568`) to the head and is evaluated against the pre-hit node, before the admit / land / read steps touch it (ADR 0083 §4; the gather's own read comes after the riders, so the two differ on purpose). Every copy, centre copies included, points at the head through `paired`, so `CritRoll.decide` copies it (`crit_roll.gd:53-62`) and a copy never re-evaluates. The crit stream then draws once per spell arrival rather than once per own hit, so a recorded fixture whose crit sequence moves is re-recorded (Acceptance 12). `paired` also makes a copy `rider_gated` by the head, as riding landings already are. If a spell copy turns out wrongly gated, stop and report it.
- **`GoOff`** is the empty base #{defs} placed in `elements/`, sitting on each band. This unit gives it its contract. It is handed two things: the gather's read of the node (its terrain after the generation's element riders have landed as sums, never the pre-beat snapshot; ADR 0083 §1, §5) and the hit's load (the head's; 0 on a copy). It returns four things: the spend, the nodes reached (other nodes only, the centre excluded, by shape alone), the share, and its own damage. The spend return also says where the spent stacks go: by default they are voided, but a go-off may name, per reached node, how many of them land there. That is the seat for Lightning's Charge transfer (ADR 0084 §7, a knob that #{lightning} defaults to transfer); Burning and Frozen keep the void. The gather commits the spend as returned, never recounted from the reach, and commits its transferred stacks in the same settle commit. A transferred stack belongs to the spend, not to a terrain rider, so the once-per-node cap does not bound it. Order at the read: the go-off picks its reach by shape alone, nodes already visited this hit included, and "0 reached, no go-off" is judged on that reach. The spend and any transfer cover the whole reach. The once-per-node set is applied after them and decides only which reached nodes run land and read in the next generation (tentative, not the owner's: the doc's "once per node per hit" bounds the go-off and the terrain riders, and ADR 0084's Consequences have an interior wire node get back what it gives). It makes one entry per node reached plus the centre copy, all at the returned share, and adds the own damage to the damage of each of that go-off's entries: damage × s + own damage. That the centre copy takes the own damage too is a tentative reading, not the owner's. The base default is the element law: spend 1 per node reached, 0 reached means no go-off, a spend may dig under T (ADR 0081 §1); share = its exported `share`; own damage 0. No concrete subclass ships here. #{go-off-zero} adds the disc (with a power source other than its own formula that #{burning} can swap in), and #{lightning} builds the edge (arc) subclass. No element primes until #{burning}, so the gather has no live go-off on master after this unit.
- **`Admits`** is the empty base #{defs} placed in `elements/`. This unit gives it two methods, the two seams of ADR 0083 §2; a null `Admits` admits every arrival and ends nothing. (1) At the admit step it is asked about each arrival, the head and each copy, against the terrain before that generation's riders land and with the arrival's crit and damage facts. It answers land or absorb. Only a copy can be absorbed (a direct hit lands either way, ADR 0082 §3), and an absorbed copy is dropped whole: no riders, no entry, no onward reach. (2) At the read step, after the riders land and before the node's go-offs, it is asked against the post-land terrain and the same facts. It answers whether the path ends here and the spend a break takes (0 = no break), which the gather commits with the go-off spends. #{ice}'s three answers split across the two: absorb comes only from (1), land + break only from (2). The second answer is in hand before the go-offs are read, so #{pairs}' mute can read it.
- **Where a walk ends.** `SpellResolver`'s expansion step (step 4, the terminal check `state.hops_remaining <= 0 or config.spread == null` → `_mark_terminal`) also ends at a landing whose head's second `Admits` read said the path ends: it mints no next wave from it and marks it terminal. The answer rides the head where the expansion step can read it (the drone picks: the head's `HitLanding` or its `LandingContext`). That is #{ice}'s Frozen walk-end seam, and the same expansion step is #{lightning}'s conduction seam. Inside the gather, chains and arcs stop at a Frozen node through the absorb and #{pairs}' mute, so the gather reads no path-end of its own (tentative, not the owner's).
- **The blast mark.** The gather mints one `BlastMark` per go-off it fires and stamps it on each of that go-off's entries, the centre copy included. The mark names its `GoOff` by the `Identity` id of the band that holds it (for go-off zero, the Explosive `Aspect`'s): one field on `BlastMark` and one column in the record's blast table, captured in `_capture_blast` and resolved through the identity roster in `_rebuild_blasts`, as the riders already are (`attack_record.gd`). The id form is a tentative reading, not the owner's. The column is omitted at its default, so today's records do not change. #{burning} reads it for Fire's colour and #{lightning} for the arc layer. #{go-off-zero}'s generation index, and how the disc fills the mark's `reach` and `power`, stay #{go-off-zero}'s.
- **Room for a cast's shape** (not built here; #{cast-shapes} builds it). A cast's shape adds reach in two ways, and the gather is shaped so neither needs a rewrite. A shape of another element than the node's go-off, or on an unprimed node, is a reach with no band behind it, no spend and no centre copy (ADR 0084 §5; the whole-hit paragraph's *"the shape for spells hmmm i think that one shouldn't count"*). So the step that appends a reach's list takes a list from any producer, tags its entries with their reach, and never assumes a reach has a spending band; the centre copy belongs to a band's go-off, not to that step. A shape of the same element as a primed band adds into that band's one go-off (ADR 0084 §3), for which the node pays its solo cost (ADR 0084 §4): that is why the spend is its own return and is never recounted from the reached nodes. A landing a shape adds is an ordinary entry: the go-off's share, the head as `paired` parent (so the seed's crit), and it goes through `Admits` as a copy (ADR 0084 §6). The seed node is the head and is never an entry of a shape's reach. No shape argument, field or test ships in this unit.
- **The hit's element** is read from the hit's own element riders (the `Element` def #{defs} gives a rider row). The gather must not assume a cast-level `element_of` accessor: that lands with #{forge}, long after this unit. A hit with no element rider carries none.
- **Greed guard.** `StatusInstance._greed_arms` (`status_instance.gd:143-156`) doubles `debuff`-tagged rows. Heat, Cold and Charge never pass through it, neither doubled nor spending Greed.
- **Untouched here** (ported by #{go-off-zero}): `DetonateEffect`, `BlastEffect`, the `SPENT_KEY` ledger, `LiveGate._node_spent`, `HitLanding.detonated` and the per-wave scope (`spell_resolver.gd:297,336`), shrapnel's own crit roll.
