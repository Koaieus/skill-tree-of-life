4. § What breaks the ice, "The race the owner flags cannot arise": this is pass analysis, stated flatly right after the owner's quote. It covers order independence. It does not cover two hits of one beat that both break the same node from one snapshot, which is the shatter's version of the same-beat "known consequence" in § Landing resolution. fixed: labelled "Pass reading, not an owner call", narrowed to "the order race", and the double break added as Open.
