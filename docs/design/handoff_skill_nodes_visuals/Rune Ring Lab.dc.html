Rune ring lab
Every knob for the ring-of-runes, isolated. runeRingGlow and runeRingFill move the inner and outer rim edges together — one control for the whole band. runeRingBlend switches how the runes themselves read: cutout (true 0 alpha, light/scene shows through), ink (solid band, dark engraved glyphs on top), glow (solid band, the glyphs are the brightest part).
Live — twirl every rune-ring knob
What each knob does
runeRing — band count: none / single / double / triple.
runeRingStyle — band width & density: flush (slim) / ornate (wide) / mixed (alternate per band).
runeRingBlend — cutout / ink / glow, see above.
runeRingGlow — inner+outer rim edge brightness, moved together.
runeRingFill — the band's own opacity/strength, independent of the edges.
runeRingRuneGlow — glow on the runes themselves (the cut/ink/glow marks) — independent of band fill, so a faint band can still carry blazing runes.
runeRingPad — radial gap between the runes and the ring's own inner/outer edge.
