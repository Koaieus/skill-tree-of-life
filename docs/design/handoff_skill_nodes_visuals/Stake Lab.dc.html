Stake lab
How deep is this entity invested? alloc / cap — 1/1, 1/2, 2/3, 3/3. Chrome is the new lead reading: instead of marks bolted outside the crater, staking grows/reshapes the crater's own inner rim — the metal you're already looking at gets visibly thicker and more built-up, which reads as "this node got twice as powerful" far better than a badge stuck on the side. Ticks/arc (bottom) are kept only as reference — good UI, wrong metaphor for stake; they read as timers/meters, not permanent growth.

Reading the depth
Chrome (new, default) — the crater rim splits into nested metal rings; filled rings are bright owner-tinted chrome, unfilled ones sit flat and dim as unrealized capacity. Grows the node itself, no bolt-on.
rimProfile — the cut of each ring's cross-section: smooth (soft bevel, today's default), stepped, grooved, terraced. Applies whether or not you're staked.
Pips / Rims / Unison — earlier outside-the-rim explorations, kept below for comparison.
Ticks / Arc — excellent UI, but reads as a cooldown or a resource gauge, not growth. Filed away for that future use instead.
