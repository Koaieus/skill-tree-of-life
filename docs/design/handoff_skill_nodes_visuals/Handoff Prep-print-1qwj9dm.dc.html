2. First rim \u2014 the structural wall
Built from 4 radii: pit 24 (recessed floor) · disc 24 (same radius as pit, the point sits flush) · crest 28 (bevel inset) · rim 32 (outer edge). The bevel look between crest and rim is a height(radius) function, not a fixed shape \u2014 level/terrace/smooth/sharpen below are just 4 presets of it. "No crest" is simply crest=rim (shown last) \u2014 the function should stay swappable in Godot, not hardcoded to these 5.
{{ c.label }}
Params: geomPitR (default 24) · geomDiscR (default 24) · geomCrestR (default 28) · geomRimR (default 32) \u2014 all independently tweakable in Godot. rimHeightStyle selects the height(radius) preset (level/terrace/smooth/sharpen); build it as a real function slot so a 5th/6th profile (or "no crest") drops in without new code paths.
3. Rim bonuses \u2014 tinted gems + fixed-tone holder (composable, independent)
rimTone (archetype-tinted, dims like the disk when unallocated): a groove line, optionally with small archetype-shaped inset gems (overlay). rimHolder (always neutral chrome, ignores tint/allocation \u2014 the "stable basket" pinning things down): rivets (braces) or wire scrollwork (filigree). The two are independent layers \u2014 rimHolderAlign sets whether the holder marks sit staggered between gems or joined right on top of them.
{{ c.label }}
Params: rimTone (none/groove/overlay) · rimHolder (none/braces/filigree, independent of rimTone) · rimHolderAlign (staggered/joined). Gem size is currently a fixed absolute radius \u2014 handoff note: make it relative to rim width (rim\u2013crest) so it scales with node size instead of a fixed px value.

Not a single decision \u2014 three independent mechanisms to compose from in Godot. All three at cap 3, alloc 2 below (full 0/3..3/3 matrix underneath the middle one, since stake states must always render as the complete matrix).

A \u2014 ring stacking (rimGrowth): N concentric copies of the wall, N = rC + cap\u00d7(ringWidth+ringGap). rimHeightStyle applies per ring (level/terrace/smooth/sharpen \u2014 all 4 export). Unfilled rings dim to the archetype hue (never flat gray). Params: stakeCap(1\u20134), ringGap(0\u20136), rimHeightStyle.

B \u2014 segmented dial (rimSegments): the wall splits into cap wedges, alloc of them lit, rotating slowly. Cap 1 always collapses to a plain ring (no notch \u2014 a single wedge reads as "nothing"). Composes with A (grown rings can each be their own dial).

C \u2014 well / groove (rimWell, needs rimSegments on): the wall keeps ONE fixed M-profile (raised outer+inner lip framing a recessed groove); the segmented fill sits inside the well instead of spanning the whole rim. rimWellGrow: fillOnly = groove fixed, fill consumes more of it as cap rises; both = groove (and the wall's outer edge) grows outward with cap too. 6. Rune ring \u2014 parametrization
A spinning band (or 2\u20133 concentric bands) with rune-like marks written into it, positioned auto-clear of whatever the rim currently occupies (gap/spacing measured from the node's actual current outer edge, so it never collides with grown stake rings). Three ways the marks can read: cutout \u2014 the band is a solid ring with the runes punched to true 0 alpha (the scene/glow behind shows through the gaps); ink \u2014 band stays solid, runes engraved as dark marks on top; glow \u2014 band stays solid, runes are the brightest part, lit instead of inked.
