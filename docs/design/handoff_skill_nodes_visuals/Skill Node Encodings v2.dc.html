Skill Node Allocation — round 2, from review
Encodings v2 — segment, grow, or both
Picking up from the 1b segmented ring lead and the concentric-rim runner-up. New rule carried through every section below: core glow is binary — off at 0, one fixed brightness for any allocation >0 — so all the "more invested" signal lives in the ring, not the disc. 1/1 now renders as a plain full ring, never a notch. ArcheNode V2 now bakes in the reviewed crater geometry (rim 32 / crest 28 / pit 24 / disc 24) as its actual default, not a prop override.

Segmented ring, refined
Fix: max = 1 draws a plain solid ring — no notch, no gap. Only max ≥ 2 splits into wedges, and only those rotate slowly (a static 1/1 next to a slowly-turning 1/2 makes the "how much room is left" read obvious without a number).

Growing footprint — ring + disc scale with max
No segments here — a continuous arc-fill like the original 1a, but ring thickness and disc diameter both grow with max, independent of alloc. A 4-max node is visibly bigger (and has a bigger hit target) than a 1-max node even before anyone invests in it — "this one can become powerful" reads at a glance across an entire tree.

Rim two-tone — constant metal base, archetype gems on top
Alternative to welding the archetype shape onto the disc: keep the disc owner-color only, keep the rim a constant gold/steel band for every node, and inset small archetype-tinted gems (count = max) directly into that band.
