Ring style — flush / ornate / mixed
Flush — slim band, runes sit neatly inside with a bright edge line top and bottom, faint tinted wash bleeding onto the node face. Ornate — wider band, runes flow closer to the rim, extra framing lines — an incantation-circle feel. Mixed — alternates style band-to-band, so a triple ring can pair a slim inner band with an ornate outer one.
