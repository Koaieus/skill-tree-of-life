1Skill Node Allocation — 14 Encodings

Each row is one visual language for the same rule: Player Tint glows the central disk, Type Tint colors the rim. Unallocated states carry no core fill/glow and a dim rim. Every row runs the same 9-state matrix (0/1 → 3/3) so you can compare how "0/2 (unspent potential)" reads against "1/1 (spent, no more room)" against "1/3 (spent, huge headroom)" side by side. Demo colors: Player Tint = cyan, Type Tint = red (swappable — see 1o for the tint palette).
