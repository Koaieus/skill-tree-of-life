Encoding archetype without color
Color belongs to the owner — every player and enemy claims a hue, so the disk fill can be anything. That frees color entirely but leaves archetype (STR / DEX / WIS / INT / PER / CON) needing a channel that survives any fill color. Below, nine ways to carry it — icons, silhouettes, and ring profiles — each rendered across all six archetypes on the same canonical disk. Every option keeps the round node as the default read; the differences are deliberately restrained so a whole tree still scans as one family.
