Skill Tree of Life — Node Design · v2
Two Colors, One Node
Your feedback, made visual. The hard problem is a 2-dimensional color space — every node carries an archetype (STR/DEX/INT/WIS/PER, fixed for life) and an owner (one hue per player, enemies included). Fat saturated rings for both = a clash matrix. Below: three ways to resolve it, the 3D button kept as the color anchor, enemy identity that isn't just "all red," addons that actually look like what they do, and self-loops.

2 · The allocated disk — kept & promoted
Your favorite. Now the primary color anchor: it holds the owner hue.
Unallocated — dark glass
Allocated — owner-tinted
Built to catch light — and later, a Godot shader
The disk is a glass cabochon: top-left specular, a radial body that darkens to the base, a contact shadow beneath, and a bottom-inner occlusion crescent. It reads as a physical, pressable object even flat in SVG. In Godot this is exactly the surface you described — a spherical SphereMesh/shader dome that can pick up environment reflections: passing projectiles, lit edges, the cursor glow, all mirrored across its curvature. The design here just makes sure the 2D fallback already feels three-dimensional so the shader is an enhancement, not a crutch.
3 · Player & enemy identity
Owner = free hue. Hostility = a shared texture, not a shared color.
Each player owns a hue — no fixed "blue = you." Enemies keep their own hue too (so two enemies never blur together), but wear a serrated hazard ring and a shared red danger aura. Result: "this is hostile" reads instantly from the texture; "which enemy" reads from the hue. No "all enemies are red" collision.

5 · Self-loops (degree +2)
An edge from a node to itself — mathematically +2 degree, with real gameplay weight (cast tier, blade joints). Drawn as a small loop tangent to the node, dropped into the least-occupied angular sector so it never collides with outgoing edges. A degree pip keeps the count honest.

6 · Core nodes — the class glyph
The core keeps the in-game convention: a large class glyph embossed on the disk, tinted to its archetype. Same planetary-emblem set every node uses at small scale — so a core reads as "the big version of this discipline," not a separate visual language.
